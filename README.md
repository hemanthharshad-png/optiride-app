# 🚍 OptiRide: Urban Mobility & Transit Aggregator

An urban mobility application built with React Native and Firebase, designed to streamline transit tracking and fare aggregation. 

This repository contains the Phase 1 UI prototyping code and initial environment configuration.

## 🛠️ Tech Stack
* **Frontend:** React Native, Expo
* **Backend & Auth:** Firebase (Configuration pending)
* **Language:** JavaScript

## 🚀 Current Status
* Configured React Native environment via Expo.
* Implemented Tier-1 Midnight Indigo Login UI and Splash Screen.
* Designed core UI layouts for the transit dashboard.

## 💻 Local Setup
1. Clone the repository.
2. Install dependencies: `npm install`
3. Start the Expo server: `npx expo start`
